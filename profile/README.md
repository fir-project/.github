# FIR

**Free. Independent. Reproducible.**

FIR is a small, independent Unix-like operating system. Declarative, reproducible
package management inspired by [Nix](https://nixos.org); minimal by default,
opinionated on purpose. Free software under the GNU GPLv3.

**Website:** [firproject.org](https://firproject.org)

## Repositories

| Repository | What it is |
|---|---|
| [fern](https://github.com/fir-project/fern) | init system and service supervision |
| [fir-utils](https://github.com/fir-project/fir-utils) | core utilities |
| [fwm](https://github.com/fir-project/fwm) | window manager for Xorg |
| [firproject](https://github.com/fir-project/firproject) | meta: roadmap and cross-project issues |

## Principles

- **Free** — run it, study it, share it, change it. Everything ships under
  GPL-3.0-or-later.
- **Independent** — built by its own contributors. No company and no parent
  distribution decides where it goes.
- **Reproducible** — same inputs, same outputs, bit for bit. Anyone can rebuild
  it from source and verify the result.

## Status

Pre-alpha. There is no installable release yet — follow the repositories for
progress.
